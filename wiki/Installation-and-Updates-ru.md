# Установка и обновление

Требования: OpenWrt/ImmortalWrt **24.10+** (opkg) или **25.12+** (apk). Рекомендуется
~40 МБ свободного места.

---

## Быстрая установка (одной командой)

```sh
wget -qO- https://raw.githubusercontent.com/ezdizzy/ravnex/master/install.sh | sh
```

Интерактивный установщик проведёт по шагам: приложение + русский язык → ядро → подписка/узел →
Hot Swap → MultiDNS → Автоматизация → Zapret 2 с автотестом → автопилот → ByeDPI.
Установщик **никогда не оставляет без интернета**: без подписки включается прямой режим и
создаётся правило «YouTube → Zapret».

Повторный запуск скрипта открывает меню настройки.

### Если GitHub недоступен

Укажите зеркало (переменная ставится перед `sh`):

```sh
wget -qO- https://raw.githubusercontent.com/ezdizzy/ravnex/master/install.sh | GH_MIRROR=https://your.mirror sh
```

Зеркало сохраняется в настройках автоматически при установке (`GH_MIRROR` в UCI пишет
`install.sh`), поэтому делегированные загрузки видят зеркало сразу.

Есть и локальный режим `--local` — установка из файлов на устройстве (например, скачанных
на Android-телефоне с терминалом и переброшенных на роутер).

## Пакеты вручную

APK (OpenWrt 25.12+):

```sh
wget -O /tmp/homeproxy-hiddify.pub https://github.com/ezdizzy/ravnex/releases/latest/download/homeproxy-hiddify.pub
cp /tmp/homeproxy-hiddify.pub /etc/apk/keys/
wget -O /tmp/app.apk "$(wget -qO- 'https://api.github.com/repos/ezdizzy/ravnex/releases' | grep -o 'https://github\.com/[^"]*luci-app-ravnex[^"]*\.apk' | head -1)"
apk add /tmp/app.apk
```

opkg (OpenWrt 24.10):

```sh
wget -O /tmp/app.ipk "$(wget -qO- 'https://api.github.com/repos/ezdizzy/ravnex/releases' | grep -o 'https://github\.com/[^"]*luci-app-ravnex[^"]*\.ipk' | head -1)"
opkg install /tmp/app.ipk
```

Ядро, ByeDPI, Zapret 2 и mosdns ставятся на странице **«Обслуживание» → «Управление ядром»** —
установщик сам определит архитектуру и подберёт сборку под свободное место (UPX-сборки
sing-box-extended/lite — для маленьких роутеров). Ядра ставятся только из **оригинальных
репозиториев** разработчиков с проверкой каждой загрузки по SHA256. Установка асинхронная,
с живым прогрессом. Подробные ручные шаги — в [Первой настройке](Getting-Started-ru).

## Самообновление приложения

Страница **«Обслуживание» → Приложение → Проверить обновление**. Версии сравниваются с последним
релизом GitHub; кнопка **«Обновить»** ставит новое приложение (и русский перевод) на место,
rpcd перезапускается автоматически — без SSH.

Если GitHub API недоступен, кнопка «Проверить обновление» честно отвечает последним известным
тегом из маленького кэша — с пометкой «данные могли устареть», а не выдуманной свежестью.

Обновления с предыдущих версий (Re:HomeProxy AutoMod 2.x) проходят без ручных шагов —
приложение уже называется Ravnex после установки новой версии.

## Свой подписанный источник пакетов (фид)

**Наши компоненты** — приложение, mosdns, хелперы автоматизации — и **наши собственные
apk/ipk-сборки DPI-движков** (byedpi ← статик-тарболы hufrea, zapret2 ← openwrt-embedded
релиз bol-van) доставляются из **нашего подписанного фида**: пакеты собираются в CI этого
репозитория и подписываются нашим ключом.

Прокси-ядра (hiddify-core, sing-box-extended, lite) **не возятся фидом** — они ставятся
напрямую из оригинальных релизов с SHA256-гейтом (см. [Управление ядром](Core-Management-ru)).

- **manifest.json — контракт клиента**: какие пакеты, версии, файлы и sha256 есть в фиде.
- Лестница скачивания: raw.githubusercontent → jsDelivr → зеркало из UCI (`github_mirror`).
- Клиент никогда не подписывает чужие репозитории в пакетный менеджер (строки `repositories.d`
  нет вовсе) — чужой репозиторий не может «переверсионить» наши компоненты.

Фид — невидимая обвязка: `install.sh` ставит ключ подписи ещё при начальной установке, а первая
установка пакета из фида лениво дотягивает ключ сама (`feed_ensure_key`). Отдельной карточки
«Источник обновлений» с кнопками **Подключить / Отключить** в UI больше нет; состояние фида видно
косвенно — в карточке **«Приложение»** на Обслуживании (баннер парности хелперов).
