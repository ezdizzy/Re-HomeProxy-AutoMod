# Установка и обновление

Требования: OpenWrt/ImmortalWrt **24.10+** (opkg) или **25.12+** (apk). Рекомендуется
~40 МБ свободного места.

---

## Быстрая установка (одной командой)

```sh
wget -qO- https://raw.githubusercontent.com/ezdizzy/re-homeproxy/master/install.sh | sh
```

Интерактивный установщик проведёт по шагам: приложение + русский язык → ядро → подписка/узел →
Hot Swap → MultiDNS → Автоматизация → Zapret 2 с автотестом → автопилот → ByeDPI.
Установщик **никогда не оставляет без интернета**: без подписки включается прямой режим и
создаётся правило «YouTube → Zapret».

Повторный запуск скрипта открывает меню настройки.

### Если GitHub заблокирован

Укажите зеркало (переменная ставится перед `sh`):

```sh
wget -qO- https://raw.githubusercontent.com/ezdizzy/re-homeproxy/master/install.sh | GH_MIRROR=https://your.mirror sh
```

Есть и локальный режим `--local` — установка из файлов на устройстве (например, скачанных
на Android-телефоне с терминалом и переброшенных на роутер).

## Пакеты вручную

APK (OpenWrt 25.12+):

```sh
wget -O /tmp/homeproxy-hiddify.pub https://github.com/ezdizzy/re-homeproxy/releases/latest/download/homeproxy-hiddify.pub
cp /tmp/homeproxy-hiddify.pub /etc/apk/keys/
wget -O /tmp/app.apk "$(wget -qO- 'https://api.github.com/repos/ezdizzy/re-homeproxy/releases' | grep -o 'https://github\.com/[^"]*luci-app-ravnex[^"]*\.apk' | head -1)"
apk add /tmp/app.apk
```

opkg (OpenWrt 24.10):

```sh
wget -O /tmp/app.ipk "$(wget -qO- 'https://api.github.com/repos/ezdizzy/re-homeproxy/releases' | grep -o 'https://github\.com/[^"]*luci-app-ravnex[^"]*\.ipk' | head -1)"
opkg install /tmp/app.ipk
```

Ядро, ByeDPI, Zapret 2 и mosdns ставятся на странице **«Обслуживание» → «Управление ядром»** —
установщик сам определит архитектуру и подберёт сборку под свободное место (включая компактную
UPX-сборку для маленьких роутеров). Установка асинхронная, с живым прогрессом. Подробные ручные
шаги — в [Первой настройке](Getting-Started-ru).

## Самообновление приложения

Страница **«Обслуживание» → Приложение → Проверить обновление**. Версии сравниваются с последним
релизом GitHub; кнопка **«Обновить»** ставит новое приложение (и русский перевод) на место,
rpcd перезапускается автоматически — без SSH.

Обновления с предыдущих версий (Re:HomeProxy AutoMod 2.x) проходят без ручных шагов —
приложение уже называется Ravnex после установки новой версии.

## Свой подписанный репозиторий (фид)

Все компоненты — ядра, DPI-движки, помощники — доставляются из **нашего фида**: это зеркала
официальных релизов апстримов, пересобранные под нашей подписью в CI этого репозитория.

- **manifest.json — контракт клиента**: какие пакеты, версии, файлы и sha256 есть в фиде.
- Лестница скачивания: raw.githubusercontent → jsDelivr → зеркало из UCI (`github_mirror`).
- Клиент никогда не подписывает чужие репозитории в пакетный менеджер (строки `repositories.d`
  нет вовсе) — чужой репозиторий не может «переверсионить» наши компоненты.
- Для byedpi / zapret2 честный фолбэк: без фида пакет скачивается с asset-пути апстрима.

Статус фида виден на странице **«Обслуживание» → карточка «Источник обновлений»**: наличие
ключа, доступность и свежесть манифеста, таблица «установлено → в фиде» по каждому компоненту,
кнопки **Подключить / Отключить**.
