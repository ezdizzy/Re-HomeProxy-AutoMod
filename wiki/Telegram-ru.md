# Управление с телефона

Telegram-бот — полноценный пульт Ravnex: статус, узлы, контроль дома, подписки, снапшоты и
пуш-уведомления. Страница настройки — **«Управление с телефона»**.

---

## Подключение бота

1. Создайте бота у **@BotFather** и вставьте токен на странице «Управление с телефона».
2. Напишите боту первое сообщение — ваш чат привязывается как чат владельца.

Демон бота всегда запущен и **сам перечитывает настройки** — сохранение не перезапускает службу.
Бот управляет роутером только через внутренний API приложения (никаких прямых правок UCI/shell).

---

## Команды

**Роутер:**

| Команда | Что делает |
|---|---|
| `/status` | Состояние системы |
| `/nodes` | Список узлов |
| `/switch N` | Переключение выхода **без рестарта** ядра |
| `/service` | Управление службой |
| `/snapshot` | Снимок конфигурации |
| `/status_engine` | Состояние движков транспортного слоя |
| `/connections` | Живые соединения |
| `/close` | Закрыть соединения |

**Контроль доступа:**

| Команда | Что делает |
|---|---|
| `/menu` | Всё в кнопках |
| `/devices` | Блок / временный блок / временное разрешение / блок Wi-Fi |
| `/blocksite` | Блокировка сайта |
| `/pause` · `/resume` | Пауза и возобновление правил |
| `/wifi` | Управление Wi-Fi |

**Подписки:** `/subs` — список и статус, `/subadd` — добавить подписку по ссылке; смена режимов
устройств и удаление подписок подтверждаются явно.

---

## Произвольные команды

Владелец может выполнить произвольную команду на роутере — с **предпросмотром и подтверждением**,
таймаутом и защитой от зависаний, полным аудитом в журнале.

---

## Пуш-уведомления

- смена узла (Hot Swap) — с **человекочитаемым именем узла**;
- сбои и восстановления служб;
- события обучающего движка (выучен новый недоступный напрямую сайт и т. п.).

Пуши **дедуплицируются**: повторная тревога одной подсистемы не сыплется повторами (кулдаун),
а «восстановлено» приходит только в ответ на реально доставленную тревогу; критические
уведомления не гейтятся никогда. Категории оповещений настраиваются — лишний шум можно
отключить.

Бот остаётся на связи, даже когда **прокси-цепочка умерла** — устойчивость канала встроена.
