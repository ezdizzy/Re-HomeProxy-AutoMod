# Мастер маршрутизации

Центр управления маршрутами: две страницы, которые вместе решают, «какой ресурс каким выходом
ходит» — **«Мастер стратегий»** (движки транспортного слоя и стратегии) и **«Правила для сервисов»**
(какой сервис через какой выход ходит).

> Оба механизма работают в режиме **«Обход блокировок»**. В «Всё через узел» весь трафик
> туннелируется в основной узел, в «Напрямую» все механизмы выключены — см.
> [Маршрутизация и контроль доступа](Routing-and-Access-Control-ru).

---

## Движки транспортного слоя (DPI)

Ravnex включает два VPN-free движка — можно использовать один или оба сразу:

- **Zapret 2 (`nfqws2`)** — обработка соединений на уровне пакетов через NFQUEUE: YouTube, Discord и другие
  ресурсы идут обычным трафиком без VPN и без подписки, с быстрой работой и российским регионом.
- **ByeDPI (`ciadpi`)** — SOCKS-уровень: 47 готовых пресетов и тестер стратегий.

Включение движков — на странице **«Подключение»** (при первом включении пакет установится
автоматически); стратегии настраиваются здесь. Правила маршрутизации могут отдавать конкретный
ресурс под Zapret или ByeDPI вместо прокси — это экономит трафик подписки.

## Страница «Мастер стратегий»

### Диагностика провайдера

Показывает, какие ресурсы недоступны и как именно: напрямую или через ваши правила. Стартовая точка перед
подбором стратегий.

### Стратегии и каталог

- Готовые пресеты и **каталог стратегий** (Zapret-Manager) — импорт в один клик.
- **Генератор собственных стратегий** и редактируемый **список ТСПУ** (dpi-detect).
- **Мультистратегии nfqws2** — один процесс с несколькими профилями и отдельными hostlist'ами.

### Strategy Lab (проверка стратегий)

Фаззинг всего корпуса стратегий на **изолированной NFQUEUE** с baseline-прогоном:

- ранжирование по раундам с метриками «старт превью» и «скорость потока»;
- текущая применённая стратегия тоже измеряется (строка «current», глубокая батарея);
- хосты, которые не прошёл ни один кандидат, честно исключаются из счёта (`dead hosts`);
- вердикт — замер **на этом роутере**: расхождения до ~25% считаются шумом.

### Автоподбор (один клик)

Подбор лучшей стратегии для одного ресурса (YouTube / Discord / …): ранжирует стратегии,
применяет лучшую, делает **серверный снимок** и живую проверку — откат всегда доступен кнопкой.

### Композиция

Разные стратегии для разных ресурсов одновременно: профиль YouTube + профиль Discord + общий
запасной. Тоже с серверным снапшотом и кнопкой отката.

### Плановый автопилот

Постоянный сторож (расписание, переразметка, авто-ремонт сломавшейся стратегии с вердиктами
жив / деградация / мёртв) живёт на странице **[Автообход блокировок](Automation-Status-ru)**.

## Страница «Правила для сервисов»

### Карта порядка маршрутизации

Показывает, как решается маршрут: закрепления → правила сервисов → правила маршрутизации →
«всё остальное напрямую».

### Сервис → выход

Каждому сервису можно назначить свой выход строкой в таблице: основной узел, другой узел,
Zapret / ByeDPI или напрямую. Кнопка **«Проверить»** в строке делает живую проверку выхода.

**Проверка честна по дизайну**: сайт-оболочку (~850 КБ SPA) нельзя судить простой пробой тела —
верный вердикт `refused`/`unknown`, а для узлов дополнительно делается egress-проба.

### Варианты выхода правила

| Вариант | Поведение |
|---|---|
| **Как основной узел** | Ваш основной прокси (в режиме «Напрямую» такие правила честно отключаются — назначенные через узел ресурсы не должны уходить напрямую) |
| **URLTest-пул** | Автовыбор среди заданного набора узлов, со своим интервалом теста и допуском |
| **Конкретный узел** | Указанный сервер |
| **ByeDPI / Zapret** | Отдать список движку транспортного слоя вместо VPN — экономит трафик подписки |
| **Нет правила** | Домен НЕ включается в прокси-списки и идёт по общим правилам — это **не** «напрямую в российский интернет» |

### Списки-пресеты

Каждое правило = **список-источник** + **выход**. Списки поддерживаются сообществом и
**автообновляются** на роутере; вы только выбираете, какие включить:

- **Россия**: Russia Inside (1000+ доменов, itdoginfo) — обязательный набор; Re:Filter (60000+
  доменов + 25000+ IP) — база блокировок РКН; Block (ядро РКН-блокировок); Russia Outside
  (RU-сервисы — для использования за рубежом);
- **Сервисы**: YouTube, Discord, Telegram, OpenAI, Claude, WhatsApp, Twitch, Meta, Twitter/X,
  TikTok, Roblox, Google Play, Google Meet, Google AI;
- **CDN и хостинги**: Cloudflare, CloudFront, DigitalOcean, Hetzner, OVH, HODCA;
- **Игровые**: Valve/Steam, Epic, Riot, PlayStation, EA, Ubisoft, Blizzard, Nintendo, Wargaming,
  Xbox;
- **Прочее**: международные новости, аниме, HDRezka, 18+, geo-blocked.

Повторное добавление того же источника отмечается — сработает только первое правило.

### Закрепления

**«Всегда напрямую»** для конкретного хоста — закрепление из таблицы автоматизации стоит **над
всеми списками**: один хост, принудительно отправленный напрямую, сильнее любого правила.

### Правило Google AI

Отдельная строка с полной проверкой: страница открывается → модель отвечает → кнопка
**«Проверить другие узлы»** подбирает узел с «чистым» регионом, если модель отвергает текущий.

### Закрепление хостов

«Всегда через прокси» / «Всегда напрямую» для конкретного хоста:

- закрепление охватывает **ровно этот хост и его поддомены** — CDN, API и прочие домены сервиса
  живут по своим правилам;
- «всегда через прокси» идёт через главный узел **ниже** правил сервисов (включённое правило
  сервиса сильнее); «всегда напрямую» — **над** всеми правилами;
- реальный маршрут любого сайта проверяется кнопкой **«Проверить маршрут»**.

### Расширенные правила (эксперт)

Свёрнутая группа для сырых правил — для тех, кто точно знает, что делает.
