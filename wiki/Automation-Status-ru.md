# Автообход блокировок

Страница **«Автообход блокировок»** — домен обучающего движка и планового автопилота. Это
справочник пользователя: что система делает сама, как читается её вердикт и какие у неё границы.

---

## Движок самообучения

Автоматически изучает заблокированные сайты: трафик, который **не проходит напрямую, но
работает через прокси**, добавляется в списки правил маршрутизации.

- **Источники кандидатов**: DNS-запросы (перехват до установления соединения), списки Clash,
  захват SNI встроенным сниффером.
- **Проверка кандидата дважды**: напрямую и через основной путь. В список попадает только то,
  что не работает напрямую, но работает через прокси.
- **Мгновенное применение (INSTANT)**: выученное применяется hot-reload'ом — **без разрыва
  соединений** и без рестарта ядра.
- **Совместимость**: полностью совместимо с ByeDPI и Zapret — выученные сайты просто используют
  ваш основной путь.

### Типы блокировки (вердикт по ресурсу)

Движок различает, **как именно** ресурс блокируется, и показывает это в таблице:

| Бейдж | Что означает |
|---|---|
| `tls_dpi` | DPI-фильтрация по TLS-метаданным |
| `dns_poison` | Подмена DNS-ответа |
| `stub` | Заглушка провайдера |
| `sigpage` | Страница отказа (блок по сигнатуре) |
| `hardcode` | Зашитый адрес |
| `upstream_blocked` | Блок на стороне апстрима |

### Таблица ресурсов

- Колонка **«Ресурс»** — домен или IP-адрес; колонка **«Тип»** — вид ресурса и вердикт проверки.
- Записи пишутся атомарно — статус-карточки никогда не показывают «половину файла».

### Защита российского интернета

Домены **`.ru`, `.рф`, `.su` никогда не проверяются** и не попадают в прокси-списки: при старте
движок удаляет ранее выученные `.ru`-домены из списка. Российские ресурсы всегда идут напрямую.

### Когда движок на паузе

- в режиме **«Всё через узел»** — туннелируется всё, учить нечему;
- при Основном узле **«Напрямую»** — нет прокси-стороны для проверки;
- в режиме **«Напрямую»** — все механизмы выключены.

Пауза честно показывается на странице с причиной — включите «Обход блокировок», чтобы продолжить.

## Автопилот DPI

Постоянный сторож стратегий обхода (в отличие от разового **автоподбора** на
[«Обход блокировок»](Routing-Master-ru)):

- по расписанию переразмечает проверенные стратегии и применяет лучшую для каждого ресурса;
- когда ресурс перестаёт отвечать — сразу применяет следующую альтернативу;
- **вердикты**: жив / деградация / мёртв — каждая смена обоснована замером;
- каждое применение делает **серверный снимок** (откат всегда доступен) и проверяет ресурс
  вживую;
- настройка: включение, ресурсы, интервал переразметки, ночной автоподбор.
